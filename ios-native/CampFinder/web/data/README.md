# Camp Finder data

`camps-au.json` is a database of camps, caravan parks, boat ramps, dump points, fuel stations, water points,
low clearances and towns extracted from OpenStreetMap by `tools/build_camp_data.py`.

It is © OpenStreetMap contributors and is made available under the
[Open Database Licence (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/). See
[openstreetmap.org/copyright](https://www.openstreetmap.org/copyright).

Other files keep their own sources and licences: Queensland Parks campgrounds (`../qpws-camps.js`, from
parks.qld.gov.au, © State of Queensland) and the price guide (`prices.json`, Camp Finder's own).
